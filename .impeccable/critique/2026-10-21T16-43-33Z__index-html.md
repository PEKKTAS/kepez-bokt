### Design Specificity Verdict

**LLM Assessment:**
The landing page possesses an exceptionally authentic brand foundation rooted in Azerbaijani national heritage. The namesake **Mount Kapaz (Kəpəz dağı)** in the Lesser Caucasus (3,065m) directly powers the cinematic drone ascent and core narrative: *"Zirvəyə aparan maliyyə həlləri"* (Financial solutions leading to the summit). The product offerings represent genuine, regulated Azerbaijani Non-Bank Credit Organization (BOKT) operations (collateralized home credit, gold Lombard valuation up to 120%, auto loans, and agro/industrial leasing under Central Bank License № BKT-22). 

However, visual tropes from global fintech aesthetics (Apple / Linear / Banco Plata 3D chrome icons, floating metallic debossed debit cards, and Bento grid cards) create a subtle friction: the interface feels like an ultra-high-end international digital gallery, yet lacks standard local conversion mechanisms (an interactive loan calculator, direct online application forms, or instant WhatsApp consultation triggers).

**Deterministic Scan & Technical Evidence:**
- The mechanical detector reported 3 warnings in `src/style.css`:
  - 2x `bounce-easing` (lines 934, 954): `cubic-bezier(0.34, 1.56, 0.64, 1)` creates a rubber-band overshoot on 3D visual hover that clashes with high-end financial restraint. (True Positive)
  - 1x `layout-transition` (line 156): `transition: width` on `.preloader-bar` triggers layout recalculation instead of GPU-composited `transform: scaleX()`. (Architectural True Positive)
- The detector's AST parser was degraded on `index.html` (missing optional parser modules), resulting in a blind spot for cascaded HTML/CSS contrast and ARIA attributes.
- Deep code inspection revealed critical technical findings:
  - **Focus Visibility Defect:** Exactly **zero** `:focus-visible` styles across the entire stylesheet; tabbing gives no visible feedback.
  - **Color Contrast Failure:** `.card-legal-note` (#94A3B8 on #FFFFFF) has a contrast ratio of **2.56:1**, failing WCAG AA (minimum 4.5:1).
  - **Asset & Memory Weight:** 181 canvas frames total **102.6 MB** payload and consume up to **~2.67 GB** of decoded bitmap memory on 2K displays, presenting high crash risks on mobile devices.
  - **Preloader SPOF:** If JS or image loading fails, the fixed black preloader never fades out, locking the user out with no `<noscript>` fallback.

**Visual Overlays:**
CLI and code analysis confirmed specific elements requiring immediate hardening. No persistent browser overlay was injected to avoid interfering with the live GSAP scroll engine.

However, the experience currently functions as an interactive brochure rather than a high-converting financial tool because users cannot calculate repayments or submit an application directly.

### Priority Issues (P0–P3)

#### [P0] Dead CTA & Card Interaction Affordances
- **Why it matters:** Bento cards show a hoverable "Daha Ətraflı" badge with arrow icons, but they are inert `<div>`s with no click handler or modal. "Müraciət et" smooth-scrolls to the 3D card, and "Depozit Yerləşdir" jumps to the static footer. Visitors have no way to actually apply for loans online.
- **Fix:** Connect "Daha Ətraflı" and "Müraciət et" triggers to a clean slide-over modal or lead form capturing Name, Phone, and Desired Amount.
- **Suggested Command:** `/impeccable shape`

#### [P1] Preloader Bandwidth & Memory Choke (181 Frames / 102 MB)
- **Why it matters:** Preloader blocks page display until all 181 WebP frames load, stalling for 10-20 seconds on mobile 4G/LTE. Simultaneously holding 181 2K bitmaps in memory consumes up to 2.67 GB of RAM, threatening to crash mobile browsers.
- **Fix:** Fade out preloader on first frame load (`frame_0001.webp`), lazily stream subsequent frames, and replace canvas scrubbing with an optimized video or poster on mobile devices (`max-width: 768px`).
- **Suggested Command:** `/impeccable optimize`

#### [P1] Missing Interactive Loan Calculator
- **Why it matters:** Collateral and auto loan borrowers evaluate lending decisions based on monthly repayment amounts. Without a calculator, potential clients bounce to competitors to calculate loan amortization.
- **Fix:** Introduce an interactive Loan Calculator block between the Bento grid and the Cashback section with Loan Amount (₼) and Term (months) sliders, live monthly payment display, and a 1-tap "Müraciət et" trigger.
- **Suggested Command:** `/impeccable shape`

#### [P2] Trapped Navigation During 680vh Hero Video Scrub
- **Why it matters:** The header bar is hidden in X-ray mode until scroll progress reaches 96%. Users seeking quick phone contact or specific credit terms are trapped inside the 680vh scrub with no shortcut.
- **Fix:** Add a minimal floating "Kreditlər / Əlaqə" anchor pill or dock the compact header after 20% scroll progress.
- **Suggested Command:** `/impeccable layout`

#### [P2] Complete Absence of Focus Visibility & Sub-44px Mobile Touch Targets
- **Why it matters:** Keyboard navigation is impossible because `:focus-visible` styles are absent. On mobile devices, language buttons (~18px) and phone links (~16px) fail WCAG 2.5.5 minimum touch target requirements (44x44px).
- **Fix:** Add accessible focus rings to all interactive elements and expand tap padding to 44px on mobile viewports.
- **Suggested Command:** `/impeccable audit`

### Minor Observations
1. **Header Phone Numbers Removed on Mobile:** In `src/style.css` line 1661, `.header-phones { display: none; }` disables direct calling from the docked header on mobile, which is the primary conversion channel.
2. **Language Switcher is a Visual Dummy:** AZ, EN, and RU toggle classes in JS, but have no translation dictionary behind them.
3. **Regulatory Clarification on "Depozit":** Under Azerbaijani banking regulations, BOKTs cannot accept insured retail bank deposits. The "15% Depozit" should specify that it is an investment debt placement (istiqraz / investisiya müqaviləsi).
4. **Bounce Easing Anti-pattern:** The `cubic-bezier(0.34, 1.56, 0.64, 1)` bounce in CSS lines 934 & 954 creates an unnecessary recoil on 3D icons.
