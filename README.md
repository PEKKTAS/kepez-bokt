# «Kəpəz» BOKT MMC — Ultra-Modern Fintech Redesign

Official ultra-modern redesign website for **«Kəpəz» Bank Olmayan Kredit Təşkilatı MMC** (AR Mərkəzi Bankı Lisenziyası № BKT-22).

## Features
- **Cinematic Drone Scrub**: Native 2K canvas video frame sequencer scrubbing with GSAP ScrollTrigger and Lenis smooth scrolling.
- **Dynamic X-Ray Header**: Apple/Banco Plata-inspired centered difference-blend logo that docks into a floating pill navigation once the slogan clears.
- **Sequential Cloud Slogan**: Two-stage kinetic typography appearing in the summit clouds with generous reading holds.
- **3D Bento Grid**: Real loan and leasing products with customized floating chrome 3D visuals and responsive mobile order hierarchy.
- **Loyalty 15% Interest Discount**: Featuring desynchronized 3D rotating Manat coins.
- **Fərdi Müştəri Kartı Showcase**: 3D levitating personal customer credit disbursement card with interactive lighting and realistic bevels.
- **Official Contacts**: Accurate license information, city and mobile/WhatsApp lines, and verified social media channels.

## Tech Stack
- HTML5 / CSS3 (Onest Google Font)
- JavaScript (ES Modules)
- GSAP + ScrollTrigger
- Lenis Smooth Scroll
- Vite
